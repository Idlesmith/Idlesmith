# Idlesmith

Small tools for people who work with AI coding assistants.

- **[idleShift](https://github.com/Idlesmith/idleShift)** — a local blackboard that lets Claude Code, Codex and Antigravity share goals and tasks on one Windows PC. Reset the chat, not the progress.
- **[quota-clock](https://github.com/Idlesmith/quota-clock)** — track 5-hour and weekly usage windows of AI coding assistants from one CLI.
